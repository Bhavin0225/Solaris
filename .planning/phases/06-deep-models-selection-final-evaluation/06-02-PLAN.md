Create src/swf/evaluate/prob.py with module docstring "Probabilistic metrics (EVAL-08): coverage, width, pinball, reliability". Functions:
- `QUANTILES = (0.1, 0.5, 0.9)`.
- `pinball(y, pred, q) -> float`: mean of max(q*(y-p), (q-1)*(y-p)).
- `prob_metrics(y, p10, p50, p90) -> dict`: n, coverage = mean((p10 <= y) & (y <= p90)), width = mean(p90 - p10), pinball = mean of pinball at the three quantiles; NaN values for n == 0.
- `reliability(y, p10, p50, p90) -> list[tuple[float, float]]`: [(0.1, mean(y <= p10)), (0.5, mean(y <= p50)), (0.9, mean(y <= p90))].
- `prob_rows(frames: dict[str, DataFrame], target, s, cfg) -> DataFrame`: frames are long-format frames (one per model) that carry p10/p90. Index each by (issue_time, horizon) for `target`, inner-join on y_true (raise ValueError if y_true differs, mirroring align_models), build the shared mask (finite y and all three quantiles for every model; daytime_mask at target_time for DAYTIME_TARGETS using cfg.eval.daytime_zenith_deg). Raise ValueError naming any model whose p10 or p90 is entirely NaN (persistence/climatology have no bands and must not be passed). Return rows: target, model, n, coverage, width, pinball, rel_q10, rel_q50, rel_q90.
Never import matplotlib here.

tests/test_evaluate_prob.py: the four behaviours above with hand-computed values, plus a prob_rows test on two tiny make_long frames (one with a NaN p10 row that must drop from both models' samples, and t1_kw night rows excluded via a target_time at local midnight).
