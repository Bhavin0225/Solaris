<objective>
Train LightGBM as a direct multi-horizon residual model on baseline 3 (D-07), one booster per target and horizon bucket (D-08), score it on validation in the common long format with empirical residual-quantile bands (D-09, MODEL-04), and write the artifacts plus `models/registry.json`.

Purpose: Success criterion 5: LightGBM on the validation leaderboard next to baseline 3 with sorted, clipped bands. The registry this writes is what the API serves; per D-13 it pins baseline3 for every target and keeps LightGBM as a recorded candidate for Phase 6 (MODEL-05). Per D-14, early stopping uses a held-out training tail; 2024 is used only for bands and the leaderboard row.
Output: swf.models.lgbm, 15 text boosters + sidecars, val/lightgbm.parquet, registry.json, refreshed leaderboard.
</objective>
