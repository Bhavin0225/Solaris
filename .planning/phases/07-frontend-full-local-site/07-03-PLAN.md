  <name>Frontend pure helpers</name>
  <files>frontend/src/lib/{time,forecast,weather,corr,targets}.ts, frontend/tests/{time,forecast,weather,corr,targets}.test.ts</files>
  <behavior>
    time.ts (all take tz from the API, e.g. 'Asia/Kolkata'):
    - makeFmt(tz).hour(Date.parse('2026-11-09T16:00:00Z')) -> '21:30' (Intl en-IN, hourCycle 'h23')
    - makeFmt(tz).day(Date.parse('2026-11-11T06:00:00Z')) -> 'Wed 11 Nov' (built from formatToParts, no comma)
    - makeFmt(tz).dayTime(ms) -> 'Wed 11 Nov, 11:30'; makeFmt(tz).longDate(ms) -> 'Wednesday, 11 November'
    - istParts(ms, tz) -> { hour, minute, y, m, d } in that zone
    - istTicks(start, end, tz) returns epoch ms of each local 00:00/06:00/12:00/18:00 inside [start, end]; for 2026-11-09T16:00Z..2026-11-12T15:00Z the first tick is 2026-11-09T18:30Z
    - istMidnights(start, end, tz) returns only the local 00:00 epochs
    - greeting(hour): 5..11 'Good morning', 12..16 'Good afternoon', else 'Good evening'
    - ageText(190) -> '3 h 10 min'; ageText(45) -> '45 min'
    - dataThrough(runTimeIso) -> epoch ms of run_time + 1 h (D-44)
    forecast.ts:
    - buildRows(forecast) -> Row[] of length = shortest points list (72 for real data); Row = { t: epochMs, [key]: { p50, p10, p90, band: [p10,p90] | null } }; band null when p10 or p90 is null
    - sliceHours(rows, 24) returns the first 24 rows (same array identity for 72)
    - currentIndex(rows, nowMs) = last index with t <= nowMs, else 0 (Pitfall 8)
    - peakOf(rows, key) -> { t, p50 } of max p50, null when all null
    weather.ts:
    - condition(precip, cloud, isDay): precip >= 0.5 -> 'rain'; cloud >= 70 -> 'cloudy'; cloud >= 30 -> 'partly' (night 'partly-night'); else 'sunny' (night 'clear'); nulls treated as 0
    - CONDITION_LABEL maps to 'Rain' | 'Cloudy' | 'Partly cloudy' | 'Sunny' | 'Clear'
    - dayAggregate(points, tz) groups by local date in order: { dateKey, firstMs, high, low, rainMm, condition }; day condition = 'rain' if any daytime hour is rain, else thresholds on mean daytime cloud (no daytime hours -> mean of all hours, night icons not used for day cards)
    corr.ts:
    - corrSentences(targets, matrix, labels) -> up to 4 { a, b, r, text } for off-diagonal |r| >= 0.5 sorted by |r| desc; text "{A} and {B} rise together (r = 0.99): {reason}" or "move in opposite directions"; reasons keyed by unordered pair per UI-SPEC (ghi|t1_kw, t5_kw|ws10, ghi|rh, rh|t1_kw, rh|ws10); other pairs end after the r clause; r formatted to 2 decimals
    targets.ts:
    - TARGETS ordered [t1_kw, t5_kw, ghi, rh, ws10] each { key, label, short, unit, decimals, simulated, hue: 'var(--hue-<key>)' } with labels/units/decimals from the UI-SPEC table ('Solar output' kW 0, 'Wind output' kW 0, 'Sunlight (GHI)' W/m² 0, 'Humidity' % 0, 'Wind speed (10 m)' m/s 1; short Solar/Wind/Sun/RH/WS)
    - modelName('tft') 'TFT', 'baseline3' 'Baseline 3', 'lightgbm' 'LightGBM', 'lstm' 'LSTM', 'gru' 'GRU', 'persistence' 'Persistence', 'climatology' 'Climatology'; unknown -> runtime with '_' replaced by ' '
    - isSimulated('t1_kw') and ('t5_kw') true, others false
  </behavior>

Tests live in frontend/tests/ (outside src so `tsc -b` needs no node types, Pitfall 11), import with explicit `.ts` extension, use `node:test` and `node:assert/strict`. RED commit with failing tests, then GREEN. Run with `node --test "tests/**/*.test.ts"` (the npm script is added by 07-02; call node directly here so this plan does not depend on it).
