|----------|-------|

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gap inside badges, tooltip row gap |
| sm | 8px | Gap between chips/badges, phone shell inset, segmented-toggle inner padding |
| md | 16px | Gap between cards, card padding on phone, desktop shell inset, gap sidebar-to-panel |
| lg | 24px | Card padding on desktop, gap between page sections |
| xl | 32px | Content-panel padding on desktop |
| 2xl | 48px | Space above the footer |
| 3xl | 64px | Bottom-nav height on phone (content gets `padding-bottom: 96px` = 64 + 32) |

Exceptions:
- **12px** allowed for: gap between icon chip row and the big number inside a card; gap between sidebar icon and label; vertical gap between greeting and its subtitle. (Multiple of 4.)
- Touch targets on phone (< 1024px): every button, toggle segment, chip and nav item is at least **44px** tall. Desktop segmented toggles are 36px tall.
- Fixed sizes: sidebar width 240px; top bar height 64px desktop / 56px phone; icon chip 32px circle; Settings button 40px desktop / 44px phone; sidebar nav item 40px tall.

**Radii** (separate scale): 12px (tooltips, small chips, skeleton blocks, hourly-strip highlight, outer corners of matrix grids; inner matrix cells are square), 20px (cards), 28px (sidebar, top bar, content panel), 9999px (pills: nav items, buttons, badges, segmented toggle).

## Typography

Exactly four sizes and two weights. All numbers use `font-variant-numeric: tabular-nums`.

| Role | Size | Weight | Line Height | Used for |
|------|------|--------|-------------|----------|
| Label | 12px | 500 (700 for uppercase group labels, letter-spacing 0.08em) | 1.4 | Sidebar group labels, sub-labels, axis ticks, badges, footer, unit suffixes on small values, "from Open-Meteo" tags |
| Body | 14px | 500 (700 for card titles, buttons, nav active item) | 1.5 | Body text, nav items, card titles, table cells, tooltip text, unit suffixes beside big numbers |
| Heading | 28px | 700, letter-spacing -0.02em | 1.2 | Greeting / page titles, big card numbers (P50 now, kWh totals, skill %), donut and ring centre values |
| Display | 48px | 700, letter-spacing -0.03em | 1.0 | Weather page current temperature only |

Rules:
- Units are a 14px weight-500 muted suffix next to a 28px number ("612 kW" → `612` 28/700 + ` kW` 14/500 muted).
- Nothing below 12px anywhere.
- About page prose: Body 14px, max width 72ch.
- Phone keeps the same four sizes (greeting may wrap to two lines).

## Accessibility Floor

- Contrast: text >= 4.5:1, chart strokes and UI boundaries >= 3:1 (ratios in the Color tables).
- Every icon-only control has `aria-label`; every icon next to text is `aria-hidden`.
- Segmented toggles: `role="radiogroup"` with `role="radio"` + `aria-checked`, arrow-key navigation.
- Charts: each chart card has an `aria-label` sentence summarising it ("Solar output forecast, next 72 hours, peak 642 kW at 13:00 IST tomorrow"); P50 values also readable in the target cards.
- Colour never carries meaning alone: skill shows a sign, the heatmap and correlation cells print values, the warning badge has text.
- Focus-visible ring on all interactive elements (accent, 2px, offset 2px).
- `<main>`, `<nav aria-label="Primary">`, one `<h1>` per page (the header title).
