Contracts this plan creates (binding for Plans 03-07):
- `history_frame(canon, s, curve, coefs=None) -> DataFrame` columns exactly TARGETS = ("t1_kw","rh","ghi","ws10","t5_kw"), float64, same index as canon.
- longfmt: LONG_COLS = ("issue_time","horizon","target_time","target","model","y_true","p10","p50","p90"); dtypes issue_time/target_time datetime64[ns, UTC], horizon int16, target category (categories = TARGETS in order), model category, y_true/p10/p50/p90 float32.
  `grid(origins: DatetimeIndex, horizons) -> (issue_time ndarray, horizon ndarray, target_time DatetimeIndex)` origin-major, horizon-minor.
  `make_long(issue_time, horizon, target, model, y_true, p50, p10=None, p90=None) -> DataFrame` (casts dtypes, target_time = issue_time + horizon h, p10/p90 NaN when None).
  `validate_long(df, truth=None, origins=None) -> df`; `pred_path(split, model, root=None) -> Path` = root/split/f"{model}.parquet" with safe_part on both; `write_long(df, split, model, root=None) -> Path` (validate, sort by target, issue_time, horizon, zstd, tmp + os.replace); `read_long(split, model, root=None, target=None) -> DataFrame` (pyarrow filter on target when given).
- metrics: `metrics(y, p, norm, norm_kind) -> {n, mae, rmse, mbe, nrmse_pct, norm, norm_kind}`; `norm_for(target, y_shared, s) -> (float, str)`; `skill(rmse, rmse_ref) -> float` = 1 - rmse/rmse_ref (NaN if ref missing/0); `daytime_mask(target_time, s, zenith_deg) -> np.ndarray[bool]`; `align_models(frames: dict[str, DataFrame], target) -> DataFrame` wide; `scored_mask(wide, models, target, s, zenith_deg) -> np.ndarray[bool]`; `breakdown(wide, models, target, s, cfg, refs=("baseline3","persistence")) -> DataFrame`; `leaderboard_rows(wide, models, target, s, cfg, refs=(...)) -> DataFrame`.
- cfg is a FeaturesCfg (Plan 01, same wave): metrics only reads `cfg.eval.horizons`, `cfg.eval.daytime_zenith_deg`, `cfg.eval.min_shared_frac`, `cfg.monsoon_months`. Tests may pass a `types.SimpleNamespace` with those attributes so this plan does not wait for Plan 01.
