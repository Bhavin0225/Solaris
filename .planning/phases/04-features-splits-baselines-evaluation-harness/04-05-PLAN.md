<objective>
Prove the feature pipeline is causal and that training and serving compute identical features, using the synthetic history and the committed live Open-Meteo fixture. Fix build.py only if a test exposes a real defect.

Purpose: FEAT-05 (leakage test) and FEAT-06 (parity test); both are never-cut items (ROADMAP).
Scope note (checker W1): the covariate exemption tested here is the FEAT-05 "known-future covariates" exception. For stitched Historical Forecast GFS (training covariates, 2021-04..2023) the value at t + h is a short-lead analysis issued near t + h, not a forecast available at t, so it is a documented train/serve skew rather than a clean causal guarantee. The leakage test only proves the builder reads the covariate row at exactly t + h; Plan 06 quantifies the skew as the stitched-vs-lead-matched RMSE gap on validation. Lead-matched Previous Runs (val/test, serving) are issued at or before t (D-02).
Output: tests/test_features_leakage.py, tests/test_features_parity.py (and a build.py fix if needed).
</objective>
