swf.core.settings (pydantic v2, every model `model_config = ConfigDict(extra="forbid")`):

```python
class Site(BaseModel): name: str; latitude: float (ge=-90, le=90); longitude: float (ge=-180, le=180); elevation_m: float; display_timezone: str
class NasaCfg(BaseModel): start_year: int (ge=2001); end_year: int; community: str; min_interval_s: float (ge=1.0); parameters: list[str] (min_length=1, max_length=15)
class LiveCfg(BaseModel): past_days: int; forecast_days: int
class OpenMeteoCfg(BaseModel): nwp_model: str; era5_model: Literal["era5"]; probe_models: list[str]; hourly: list[str];
    previous_day_leads: list[int]; era5_years: tuple[int, int]; historical_forecast_years: tuple[int, int];
    previous_runs_years: tuple[int, int]; min_interval_s: float (ge=1.0); live: LiveCfg
class DataCfg(BaseModel): nasa: NasaCfg; openmeteo: OpenMeteoCfg
class KaggleCfg(BaseModel): solar_slug: str; wind_slug: str; row_tolerance: float (ge=0, le=0.5); expected_rows: dict[str, int]
class SolarCfg(BaseModel): dc_kwp, tilt_deg, azimuth_pvlib_deg, dc_ac_ratio, eta_inv_nom, gamma_pdc, loss_pct: float; transposition: str
class WindCfg(BaseModel): rated_kw, hub_height_m, availability_loss, cut_in_ms, rated_ms, cut_out_ms: float
class Settings(BaseModel): site: Site; data: DataCfg; kaggle: KaggleCfg; solar: SolarCfg; wind: WindCfg
def load_settings(config_dir: Path | None = None) -> Settings   # default swf.core.paths.CONFIG_DIR; Settings(**site_yaml, **plant_yaml)
```

Validators:
- `nwp_model` and every item of `probe_models`: regex `^[a-z0-9_]+$` (path-safe) AND not `best_match` (unstable alias)
- `solar_slug`, `wind_slug`: regex `^[A-Za-z0-9][A-Za-z0-9_.-]*/[A-Za-z0-9][A-Za-z0-9_.-]*$`
- every key of `expected_rows`: regex `^[A-Za-z0-9_.-]+\.csv$` (file name only, no path separators)

swf.core.paths: `REPO_ROOT = Path(__file__).resolve().parents[3]`, `CONFIG_DIR = REPO_ROOT / "config"`, `DATA_DIR = REPO_ROOT / "data"`, `RAW_DIR = DATA_DIR / "raw"`, `INTERIM_DIR = DATA_DIR / "interim"`, `DOCS_DIR = REPO_ROOT / "docs"`.

swf.core.geometry: `def to_openmeteo_azimuth(azimuth_pvlib_deg: float) -> float` returns `(az % 360) - 180` (pvlib 180=south -> Open-Meteo 0=south).
