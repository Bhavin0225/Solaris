```python
ENDPOINTS = {
  "archive": "https://archive-api.open-meteo.com/v1/archive",
  "historical_forecast": "https://historical-forecast-api.open-meteo.com/v1/forecast",
  "previous_runs": "https://previous-runs-api.open-meteo.com/v1/forecast",
  "forecast": "https://api.open-meteo.com/v1/forecast",
}
def base_params(s: Settings, model: str) -> dict      # latitude, longitude, timezone="GMT", wind_speed_unit="ms", tilt, azimuth, models
def year_params(s: Settings, api: str, year: int) -> dict   # base + hourly + start_date=YYYY-01-01 + end_date=YYYY-12-31
def live_params(s: Settings) -> dict                  # base(nwp_model) + hourly + past_days + forecast_days
def summarize(raw: bytes) -> dict                     # rows, columns, pct_missing{col}, latitude, longitude, elevation, first_time, last_time
def pr_accepts_all_leads(client, s: Settings, model: str, dest: Path, *, sleep=time.sleep) -> bool
    # 1-day Previous Runs smoke request (date f"{previous_runs_years[0]}-03-01") with all len(hourly) x len(leads) names, via fetch_to_cache to `dest`;
    # True on success or cache hit; False on httpx.HTTPStatusError with status 400 (nothing is written); other errors propagate. Plan 05 probe reuses it.
def fetch_years(client, s: Settings, api: str, years: Iterable[int], *, root: Path, force=False, sleep=time.sleep, split_leads: bool = False) -> list[str]
    # split_leads (previous_runs only): one request per lead day per year, file <year>_day<n>.json in the same <api>/<model>/ dir, hourly = 14 names for that lead
def fetch_live(client, s: Settings, *, root: Path, now: datetime | None = None, force=False, sleep=time.sleep) -> Path
def run(args: argparse.Namespace) -> int
```

Cache layout (D-11): `root/openmeteo/<api>/<model>/<year>.json` with api in {archive, historical_forecast, previous_runs}; live: `root/openmeteo/forecast/<model>/<YYYYMMDDTHH>.json` (UTC retrieval hour).
Model per api: archive -> `s.data.openmeteo.era5_model` (always "era5"); every other api -> `s.data.openmeteo.nwp_model`.
Previous Runs hourly names: `f"{v}_previous_day{n}"` for v in hourly, n in previous_day_leads (14 x 3 = 42). The 42-name request is not verified live (research tested 24 names), hence the smoke request; smoke file: `root/openmeteo/previous_runs/<model>/smoke.json` (not a year file; the coverage report only reads stems matching `^\d{4}(_day\d)?$`).
Open-Meteo response shape (single model): top-level `latitude`, `longitude`, `elevation`, `hourly_units`, `hourly` {"time": ["2024-01-01T00:00", ...], "<var>": [values or null]}.
